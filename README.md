# Case Brief Assistant

Paste the text of a court opinion and get back a structured brief (Facts, Issue, Holding, Reasoning, Rule) plus a plain English summary, generated by the Claude API.

Built the same way as [Text Humanizer](https://text-humanizer-omega.vercel.app/): a static frontend and a serverless backend function, both hosted on Vercel. The Anthropic API key lives only in the backend function and is never sent to the browser.

## How it works

- `index.html`, `style.css`, `script.js` are the frontend. The browser only ever talks to `/api/brief` on the same domain.
- `api/brief.js` is a Vercel serverless function. It receives the opinion text, sends it to the Claude API with a system prompt describing the FIRAC format, and forces a structured tool call so the response comes back as clean, predictable JSON rather than free text that has to be parsed.
- The model used is `claude-sonnet-5`.

## Run it locally

You will need [Node.js](https://nodejs.org/) 18 or later and the Vercel CLI.

```bash
npm install -g vercel
cd case-brief-assistant
cp .env.example .env.local
```

Open `.env.local` and paste in a real key from the [Anthropic Console](https://console.anthropic.com/settings/keys).

```bash
vercel dev
```

This starts the app at `http://localhost:3000` and runs the `/api/brief` function locally against the real Claude API.

## Deploy it (GitHub and Vercel, same as Text Humanizer)

1. **Push the project to GitHub.**

   ```bash
   cd case-brief-assistant
   git init
   git add .
   git commit -m "Initial commit: Case Brief Assistant"
   ```

   Create a new, empty repository on GitHub (do not initialize it with a README), then:

   ```bash
   git remote add origin https://github.com/YOUR-USERNAME/case-brief-assistant.git
   git branch -M main
   git push -u origin main
   ```

2. **Import the repository into Vercel.**

   Go to [vercel.com/new](https://vercel.com/new), choose the `case-brief-assistant` repository, and import it. Vercel will detect it as a plain static project with a serverless function and will not need a build command.

3. **Add the environment variable.**

   In the Vercel project, go to Settings, then Environment Variables, and add:

   - Name: `ANTHROPIC_API_KEY`
   - Value: your key from the Anthropic Console
   - Environment: Production (and Preview, if you want branch deploys to work too)

4. **Deploy.**

   Click Deploy. Vercel will build and give you a live URL, the same way it did for Text Humanizer. Every push to `main` after this will redeploy automatically.

## Notes

- The intake form rejects opinions under 200 characters (too little to brief reliably) and over 80,000 characters (kept as a sane limit for a demo app; raise `MAX_LENGTH` in `api/brief.js` if you need more room).
- No sampling parameters (temperature, top_p, top_k) are set on the API call. Claude Sonnet 5 rejects non-default values for those, so the function intentionally leaves them out.
- If you rename or move the project, remember `api/brief.js` must stay under an `api/` folder at the project root for Vercel to pick it up as a serverless function.
